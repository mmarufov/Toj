01 / A CLEAR UNDERSTANDING

Your conversations.
Our responsibility.

Toj is a cloud messenger. Default chats are encrypted in transit and at rest. The server holds the keys, so Toj operators can decrypt your messages. These chats are not end-to-end encrypted.

That model lets your history sync across devices. Opt-in, end-to-end encrypted Secret Chats are planned.

When can I try Toj?+

Toj isn't accepting public users yet. Development uses private staging. Public release depends on physical-device and mobile-network validation, with no launch date announced.

What's built so far?+

The code includes messaging, groups, media, on-device search, and multi-device sync. Voice and video calls are implemented but disabled pending infrastructure and release gates. Push provisioning and field testing remain launch work.

Can I explore the code?+

Yes. The iOS app and Bun backend are in the same public, source-available repository. Start with the architecture, or follow the implementation links above.
