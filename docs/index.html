02 / UNDER THE HOOD

Simple on the surface.

A / RECOVERY

A socket is a hint.
Not the source of truth.

WebSockets make updates feel immediate. Ordered HTTP differences recover what a connection missed. A per-account sequence cursor keeps catch-up explicit.

B / LANGUAGE

Your language.
Not an edge case.

On-device FTS5 search uses separate exact and folded forms. Tajik letter variants can match, while Russian ё and й retain their distinctions.

C / DELIVERY

Retry the send.
Not the message.

A stable client message ID and transactional server deduplication handle the awkward case: the server accepted your message, but its response never reached you.

Inspect the send path ↗
D / TRUST

Clear about privacy.
By design.

Cloud chats sync across devices, with encryption in transit and at rest. The server holds the keys. They are not end-to-end encrypted; optional Secret Chats are planned.

A FEW HONEST ANSWERS

Can I download Toj?+

Not yet. Toj is pre-launch and isn't accepting public users. The client and backend are developed against private staging. A public release will follow device and network validation.

What's built, and what's next?+

Messaging, groups, media, search, and sync are implemented. Calls remain disabled pending infrastructure and release gates. Push provisioning and testing on real Tajik networks are still ahead.

Can I explore the code?+

Yes. The repository is public for inspection under a source-available license. Start with the architecture, review the tests, or follow a message through the sync implementation. Explore the repository ↗
