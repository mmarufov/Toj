01 / THE EXPERIENCE

What happens when
the connection drops.

Toj saves each message on the device first, then sends it in the background and retries until the server confirms it.

Try it.

Turn the connection off, queue a message, then turn it back on. This demo runs in your browser and shows how the outbox works.

  1. 01
    Saved locally.

    The message and its pending send are written to the device in one transaction.

  2. 02
    Retried with the same ID.

    Every retry carries the same message ID, so a lost server reply can't create a duplicate.

  3. 03
    Caught up in order.

    After reconnecting, each device fetches the events it missed, in sequence.

A / RECOVERY

WebSocket for speed,
HTTP for catch-up.

The WebSocket only tells a device that something changed. The device then asks for everything since its last sequence number over HTTP, so a dropped socket can't lose an update.

B / LANGUAGE

Search for Tajik
and Russian text.

On-device FTS5 search indexes an exact and a folded form of each word. Tajik letters match their plain Cyrillic variants, while Russian ё and й stay distinct.

C / DELIVERY

Retries without
duplicates.

Each message has a client-generated ID. If the server saves a message but its reply is lost, the retry gets the saved copy back and no second message is created.

Inspect the send path ↗
D / TRUST

What the server
can read.

Cloud chats are encrypted in transit and at rest, and the server holds the keys so history can sync across devices. They are not end-to-end encrypted. Opt-in end-to-end Secret Chats are planned.

FAQ

Can I download Toj?+

Not yet. Toj is pre-launch and isn't accepting public users. It runs on a private staging server until it has been tested on real devices and mobile networks.

What's built, and what's next?+

Messaging, groups, media, search and multi-device sync work on staging. Voice and video calls are built and will be switched on once the call servers are deployed. Push notifications and field testing on mobile networks come next.

Can I read the code?+

Yes. The code is public under a source-available license. Good places to start are the architecture doc, the tests, and the sync code in server/src/sync.ts. Open the repository ↗
